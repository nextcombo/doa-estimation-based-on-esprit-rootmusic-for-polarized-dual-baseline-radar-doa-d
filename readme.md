# DOA Estimation Based on ESPRIT-ROOTMUSIC for Polarized Dual-Baseline Radar DOA-DOD Estimation [with MATLAB Code]

Polarization Diversity in Dual-Base MIMO Radar: Joint ESPRIT-RootMUSIC Estimation of DOA and DOD
This study investigates the use of polarization diversity signals in dual-base polarized MIMO radar, employing joint ESPRIT-RootMUSIC techniques to enhance the joint estimation performance of target DOA and DOD. The results are validated through numerical simulations. 
Introduction 
Multi-Input Multi-Output (MIMO) radar uses multiple transmit antennas to simultaneously emit multiple linearly orthogonal waveforms. It also utilizes multiple antennas for receiving reflected signals. In [2], a dual-base MIMO radar scheme was considered, where a two-dimensional (2-D) spatial spectrum estimation technique based on the Capon method was developed. This method requires exhaustive search throughout the 2-D space to obtain the target's DOA and DOD. 
Jin et al. [3] proposed a joint DOA and DOD estimation method based on ESPRIT technology using the same MIMO radar configuration. This method obtained closed-form expressions for the target's DOA and DOD and automatically paired them. However, the number of targets that can be located using this method is less than the number of receivers. 
Under the same structure as the dual-base MIMO radar, [5] introduced another ESPRIT-based method that leverages the invariance of the transmit array and receive array to estimate the target's DOA and DOD. This algorithm does not perform automatic pairing but provides an additional pairing operation. 
In [7], we proposed a method combining ESPRIT and Root-MUSIC to jointly estimate the target DOADOD in dual-base MIMO radar. This method allows for automatic pairing between the target's DOA and DOD. Polarization diversity has been shown to be useful for array signal processing and various types of radar systems [8,9,11,12].
In recent years, [10] has proposed an eigen-based polarimetric dual-baseline MIMO radar target parameter DOA-DOD-polarization joint estimation method based on ESPRIT technology, which requires pairing computations. In this work, we propose an extension of the technique developed in [7] by leveraging polarization diversity within the receive antenna array. In addition to polarization diversity, the method also allows for automatic pairing between the target's DOA and DOD. Simulation results confirm the effectiveness of the algorithm.

Conclusion
We have utilized the additional degrees of freedom provided by polarization diversity to improve the performance of the combined ESPRITRootMUSIC used in dual-baseline MIMO radar for joint DOA-DOD estimation. The use of polarization diversity allows for handling more targets than classical algorithms and enhances positioning performance.
